Backend Documentation

RESTful JSON API Specification

Authentication Flow

  1. Send a POST request containing credentials to /api/login to retrieve a JSON Web Token (JWT).
  2. Store the returned JWT in the browser cookies.
  3. Attach the token to the HTTP Request Header as Authorization: Bearer <token> for all protected endpoints.

Endpoints

POST /api/login

Authenticates user credentials and yields a bearer JWT token upon successful validation.

Request Body (JSON)
{
  "username": "studentUser",
  "password": "studentPassword"
}
Response (200 OK)
{
  "token": "eyJhbGciOiJIUzI1Ni..."
}
GET /api/getUserDetails 🔒 Auth Required

Retrieves detailed information about the currently authenticated user based on the provided JWT.

Required Headers
Authorization: Bearer <token>
Response (200 OK)
{
  "email": "student@school.com",
  "role": "Student",
  "username": "studentUser"
}

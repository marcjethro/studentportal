REST API Documentation

v1.0.0 • User & Access Management Specification

Authentication Flow

  1. Send a POST request with credentials to /api/auth/login to receive a JSON Web Token (JWT).
  2. Store the token securely in browser cookies.
  3. Include the token in the HTTP Authorization header for protected requests:
    Authorization: Bearer <token>

Authentication & User Details

POST /api/auth/login No Auth

Authenticates user credentials and returns an access token.

Request Body
{
  "username": "studentUser",
  "password": "studentPassword"
}
Response (200 OK)
{
  "role": "student"
  "token": "eyJhbGciOiJIUzI1Ni..."
}
POST /api/auth/forget-password No Auth

Sends a password reset link to the email of the username provided.

Request Body
{
  "username": "studentUser",
}
Response (200 OK)
{
  "msg": "Password reset link sent to user's email"
}
GET /api/getUserDetails 🔒 Any Role

Fetches profile details for the currently authenticated user.

Required Headers
Authorization: Bearer <token>
Response (200 OK)
{
  "email": "student@school.com",
  "role": "student",
  "username": "studentUser"
}
POST /api/auth/change-password 🔒 Any Role

Changes authenticated user's password.

Request Body
{
  "old_password": "studentPassword",
  "new_password": "newStudentPassword"
}
Response (200 OK)
{
  "msg": "Password changed successfully"
}

Administrative Endpoints (Role: EDP)

GET /api/auth/roles 🔒 Role: edp

Retrieves a list of all available system roles.

Response (200 OK)
[
  { "role_id": 1, "name": "student" },
  { "role_id": 2, "name": "teacher" },
  { "role_id": 3, "name": "edp" },
  { "role_id": 4, "name": "accounting" },
  { "role_id": 5, "name": "registrar" }
]
GET /api/auth/users 🔒 Role: edp

Fetches a list of all registered users in the system.

Response (200 OK)
[
  {
    "user_id": 1,
    "username": "studentUser",
    "email": "student@school.com",
    "role": "student"
  },
  {
    "user_id": 2,
    "username": "teacherUser",
    "email": "teacher@school.com",
    "role": "teacher"
  }, ...
]
POST /api/auth/users 🔒 Role: edp

Creates a new user record in the database.

Request Body
{
  "username": "NewUser",
  "email": "newuser@school.com",
  "password": "securePassword123",
  "role_id": "1"
}
Response (201 Created)
{
  "user_id": 7,
  "msg": "User created successfully"
}
GET /api/auth/users/<int:user_id> 🔒 Role: edp

Retrieves detailed information for a specific user ID.

Response (200 OK)
{
  "user_id": 1,
  "username": "studentUser",
  "email": "student@school.com",
  "role": "student"
}
PATCH /api/auth/users/<int:user_id> 🔒 Role: edp

Partially updates username, email, or password for a specific user ID.

Request Body (Partial Update)
{
  "password": "updatedPassword"
  "email": "updated_student@school.com",
}
Response (200 OK)
{
  "msg": "User updated successfully"
}
DELETE /api/auth/users/<int:user_id> 🔒 Role: edp

Permanently removes a user account by ID.

Response (200 OK)
{
  "msg": "User deleted successfully"
}

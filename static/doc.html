RESTful JSON API endpoints

Authentication Flow:

  1. Send a POST fetch request to /api/login to get a JSON Web Token (JWT)

  2. Store the token in the browser cookies

  3. Attach it to the Authorization: Bearer header for all subsequent requests.

POST /api/login

example input:

{
  "username": "StudentUser",
  "password": "studentPassword"
}

example output:

{
  "token": "eyJhbGciOiJIUzI1Ni..."
}

GET /api/getUserDetails

example output:

{
  "email": "student@school.com",
  "role": "Student",
  "username": "StudentUser"
}
